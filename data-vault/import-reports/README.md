# تقارير الاستيراد — `import-reports/`

ملفٌّ لكلّ **دفعة** (Import Batch) بمعرِّفٍ تسلسليّ `IMP-0001` · `IMP-0002` …
يُكتب **قبل** التشغيل (الخطّة) ويُكمَل **بعده** (النتيجة). ويُوضع نظيرُه
المختصر في `05-imported/` باسم الدفعة، ويُحدَّث صفُّ المجموعة في `MANIFEST.md`
(`Imported` · `Import batch` · `Verification status`).

الدفعةُ الواحدة = مجموعةُ بياناتٍ واحدة (`DATA-xxxx`) → كيانٌ واحد. دفعتان
لملفٍّ واحد (العملاء ثمّ الفواتير) = تقريران.

> يُتتبَّع في Git والمستودع عامّ: أرقامٌ وعدادٌ نعم؛ أسماءُ عملاء ومبالغُ
> صفوفٍ بعينها لا. الصفوفُ الفاشلة تُذكر **بمرجعها** (`DATA-0001#row-42`)
> لا بمحتواها.
